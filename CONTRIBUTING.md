# Dúvidas, Bugs e Contribuições

Este projeto é de código aberto e mantido de forma independente. Para que o trabalho continue organizado e sustentável, organizamos a comunicação da seguinte forma:

---

## 💬 Dúvidas e Perguntas

Se você estiver com dúvidas sobre como configurar o Docker, variáveis de ambiente ou gateways:
- Abra uma [Issue](../../issues) com a etiqueta de **Dúvida**.
- Descreva o que você está tentando fazer para que a resposta possa ajudar outras pessoas no futuro.

---

## 🐛 Encontrou um Bug?

Se algo não funcionou como esperado:
- Abra uma [Issue](../../issues) descrevendo o erro e, se possível, os passos para reproduzir o problema.
- Lembre-se de não compartilhar chaves secretas ou credenciais nos logs.

---

## 🛠️ Sobre Pull Requests

Como este é um projeto mantido no tempo livre e com escopo bem definido para atender casos de uso específicos:

- **Não abra Pull Requests sem antes conversar.**
- Se tiver uma ideia de melhoria ou ajuste no código, **abra uma Issue primeiro** para combinarmos se a mudança faz sentido para o projeto.
- Pull Requests enviados sem alinhamento prévio costumam ser fechados para não dispersar o foco do repositório.
